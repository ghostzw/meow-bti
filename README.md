# 喵BTI - 猫咪性格测试 🐱

一个有趣的H5小游戏，将人类的MBTI（迈尔斯-布里格斯类型指标）概念移植到猫咪身上，帮助铲屎官了解主子的真实性格！

## 功能特点

- 🎯 **16种猫咪人格**：从"幕后黑手猫"到"快乐修勾猫"，每种都有独特的性格描述
- 📊 **六维雷达图**：可视化展示猫咪的粘人度、破坏力、智商、掉毛率等维度
- 🎨 **精美UI设计**：渐变背景、动画效果、响应式布局
- 📱 **移动端友好**：完美适配手机和电脑
- 💾 **海报保存**：一键保存测试结果，方便分享

## 使用方法

### 方法一：直接打开（推荐）

直接用浏览器打开 `index.html` 文件即可。

### 方法二：使用本地服务器

1. 安装依赖（可选）：
```bash
npm install
```

2. 启动本地服务器：
```bash
npm start
```

或者使用其他静态服务器工具：
```bash
# 使用 Python
python -m http.server 8080

# 使用 Node.js http-server
npx http-server . -p 8080
```

3. 在浏览器中访问 `http://localhost:8080`

## 测试流程

1. **首页**：输入猫咪的名字
2. **答题页**：回答12道场景化题目
3. **加载页**：等待分析结果（3秒）
4. **结果页**：查看详细的性格分析报告

## 技术栈

- 纯原生 JavaScript（无框架依赖）
- HTML5 + CSS3
- Canvas API（雷达图绘制）
- html2canvas（海报生成）

## 浏览器兼容性

- Chrome/Edge（推荐）
- Firefox
- Safari
- 移动端浏览器

## 注意事项

- 海报保存功能需要网络连接（加载html2canvas库）
